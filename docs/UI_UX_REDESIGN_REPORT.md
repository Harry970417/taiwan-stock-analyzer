## 2. 找到並修復的缺口

### 首頁未標示資料實際更新日期

**問題**：首頁「今日市場情緒」區塊只顯示程式執行的當下時間（`update_time`），
不是資料實際反映的交易日。實測時 TWSE 官方資料最新僅到 2026-07-30，
但頁面完全沒有提示，使用者可能誤判為即時（2026-07-31）資料。

這正對應使用者需求中的「首頁應讓使用者快速知道資料更新到哪一天」。

**修復**：
- `modules/market_dashboard.py`：解析 TWSE API 回傳的民國年 `Date` 欄位，換算為西元日期
  （例：`1150730` → `2026-07-30`），存入 `result["data_date"]`。
- `app.py`：首頁在免責聲明下方新增一行 `📅 資料更新至：YYYY-MM-DD（台灣證券交易所收盤資料，
  非即時報價） · 頁面渲染時間 HH:MM:SS`；若無法解析日期則顯示警告，提示資料可能過期。

修復前後對照（實測截圖）：
- 修復前：免責聲明後直接跳到「今日市場情緒」KPI 卡片，無日期線索。
- 修復後：`📅 資料更新至：2026-07-30（台灣證券交易所收盤資料，非即時報價） · 頁面渲染時間 16:37:24`
