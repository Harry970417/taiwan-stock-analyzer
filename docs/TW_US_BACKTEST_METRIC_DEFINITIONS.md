# 台美股策略回測 — 指標定義

所有指標之計算實作皆位於 `modules/performance_metrics.py`（全站單一權威來源），跨頁面共用同一套公式，避免同一指標在不同頁面出現不同定義。

## 報酬類指標

| 指標 | 定義 |
|---|---|
| **CAGR**（年化複合成長率） | `(期末淨值 / 期初淨值) ^ (365 / 總天數) - 1`，以實際交易日曆天數年化，非固定 252 日近似。 |
| **月報酬 / 年報酬** | 以每月最後一個交易日淨值計算之期間報酬率。 |

## 風險類指標

| 指標 | 定義 |
|---|---|
| **MDD**（最大回撤，Maximum Drawdown） | 淨值曲線上任一時點相對其歷史高點的最大跌幅，`min((淨值 - 歷史高點) / 歷史高點)`。 |
| **最長回撤天數** | 淨值處於歷史高點以下的最長連續天數區間。 |
| **回撤修復天數** | 自最大回撤谷底回升至前波歷史高點所需的天數。 |

## 風險調整後報酬指標

| 指標 | 定義 |
|---|---|
| **Sharpe Ratio** | `(年化報酬 - 無風險利率) / 年化波動率`，以日報酬標準差年化。 |
| **Sortino Ratio** | 同 Sharpe，但分母僅計入下方波動（負報酬日的標準差），不懲罰正向波動。 |
| **Calmar Ratio** | `年化報酬 / |最大回撤|`，衡量每承受 1 單位回撤所換得的年化報酬。 |

## 交易層級指標

| 指標 | 定義 |
|---|---|
| **勝率（Win Rate）** | 獲利交易筆數 / 總交易筆數，交易由 `modules/trade_ledger.py` 依部位權重序列重建（持續持有視為同一筆交易，非人為製造進出場）。 |
| **Profit Factor** | 總獲利金額 / 總虧損金額之絕對值。 |
| **平均獲利虧損比（Avg Payoff Ratio）** | 平均每筆獲利交易報酬 / 平均每筆虧損交易報酬之絕對值。 |
| **週轉率（Turnover）** | 每次再平衡的部位變動幅度佔組合淨值之比例。 |
| **成本佔毛利比** | 總交易成本 / 總毛利，衡量交易成本對報酬的侵蝕程度。 |

## 組合層級與比較指標（本研究新增，用於台美股組合分析）

| 指標 | 定義 |
|---|---|
| **上漲捕獲率（Up Capture）** | 比較基準上漲期間，策略報酬相對基準報酬的比例；>1 代表策略在多頭期間表現優於基準。 |
| **下跌捕獲率（Down Capture）** | 比較基準下跌期間，策略報酬相對基準報酬的比例；<1 代表策略在空頭期間相對抗跌。 |
| **每降 1pp MDD 犧牲之 CAGR** | `(比較基準 CAGR - 策略 CAGR) / (比較基準 MDD 絕對值 - 策略 MDD 絕對值)`，量化「以報酬換取回撤控制」的精確代價；負值代表策略在該項比較上 MDD 反而更差，非正常的「權衡」關係，需個別解讀。 |
| **匯率貢獻（FX Contribution）** | `實際 TWD 計價 CAGR - 固定匯率反事實 CAGR`，拆解純匯率變動對組合報酬的貢獻，與台股腿、美股腿本身的表現分離。 |
| **相對基準超額報酬** | `策略 CAGR - 被動基準 CAGR`，正值代表策略優於基準，負值代表落後。 |

## 穩健性測試專用術語

| 術語 | 定義 |
|---|---|
| **中位數 / P10 / P90（30 組股票池抽樣）** | 30 組獨立隨機股票池抽樣結果由小到大排序後，第 50 百分位（中位數）、第 10 百分位、第 90 百分位之數值，用以描述抽樣結果的集中趨勢與離散程度，取代單一 seed 的點估計。 |
| **成本壓力測試** | 在免成本、標準（40bps）、雙倍（80bps）、壓力（120bps）四種交易成本假設下重新計算指標，檢驗結論對成本假設的敏感度。 |
| **移除最佳年度測試（公平共同年度版本）** | 移除所有比較對象共同的最佳表現年度後重新計算 CAGR，避免單一年度的特殊表現主導整體結論；「公平共同年度」指所有比較對象移除同一年度，而非各自移除各自的最佳年度，以確保可比較性。 |
